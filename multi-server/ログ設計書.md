## 2. ログ種別一覧

| ログ種別 | 内容 | 対応する証跡 |
|---------|------|------------|
| Teratermログ | コマンド実行の全操作ログ（画面表示） | コマンドログ（Teratermログ） |
| シェル実行ログ | INFO/ERROR メッセージ出力 | シェル実行ログ（メッセージ出力） |
| 詳細ログ | コマンド・ReturnCode 詳細記録 | 詳細ログ（コマンド実行結果） |

---

## 3. ログファイル命名規則

| 区分 | 規則 |
|------|------|
| シェル実行ログ | `{シェル名}_{YYYYMMDDHHMMSS}.log` |
| 詳細ログ | `{シェル名}_detail_{YYYYMMDDHHMMSS}.log` |

- `{シェル名}`：実行シェルのファイル名（拡張子なし）
- `{YYYYMMDDHHMMSS}`：実行開始日時（年月日時分秒）
- 同日複数回実行しても上書きされず、実行ごとに別ファイルとして保存される

---

## 4. ログレベル定義

| レベル | 用途 | 出力先 |
|--------|------|--------|
| `INFO` | 処理の開始・終了・正常実行結果 | シェル実行ログ・標準出力 |
| `ERROR` | エラー発生・異常終了 | シェル実行ログ・標準エラー出力 |
| `CMD` | 実行コマンドの記録 | 詳細ログ |
| `RC` | ReturnCode の記録 | 詳細ログ |

---

## 5. ログ出力フォーマット

### 5.1 シェル実行ログ（INFO/ERROR）

```
[YYYY-MM-DD HH:MM:SS] [INFO]  処理内容メッセージ
[YYYY-MM-DD HH:MM:SS] [ERROR] エラーコード: エラーメッセージ
```

### 5.2 詳細ログ（CMD/RC）

```
[YYYY-MM-DD HH:MM:SS] [CMD] 実行コマンド文字列
[YYYY-MM-DD HH:MM:SS] [RC]  ReturnCode=0
```

### 5.3 出力例（正常時）

```
[YYYY-MM-DD HH:MM:SS] [INFO]  処理開始: {シェル名}.sh
[YYYY-MM-DD HH:MM:SS] [CMD]   {実行コマンド}
[YYYY-MM-DD HH:MM:SS] [RC]    ReturnCode=0
[YYYY-MM-DD HH:MM:SS] [INFO]  処理完了: {処理内容}
```

### 5.4 出力例（エラー時）

```
[YYYY-MM-DD HH:MM:SS] [CMD]   {実行コマンド} 2>&1
[YYYY-MM-DD HH:MM:SS] [RC]    ReturnCode=1
[YYYY-MM-DD HH:MM:SS] [ERROR] {エラーコード}: {エラーメッセージ}
```

## 6. ログ初期化処理（init_log）

| ステップ | 処理内容 |
|---------|---------|
| 1 | ログ格納ディレクトリが存在しない場合、`mkdir -p` で作成 |
| 2 | シェル実行ログ・詳細ログのヘッダー行を出力（実行開始日時・スクリプト名） |

**ヘッダー出力例：**
```
========================================
 スクリプト名: {シェル名}.sh
 実行開始日時: YYYY-MM-DD HH:MM:SS
========================================
```

---

## 7. ログ出力関数一覧

| 関数名 | 役割 | 引数 | 出力先 |
|--------|------|------|--------|
| `log_info()` | INFO ログ出力 | `$1`：メッセージ | シェル実行ログ・標準出力 |
| `log_error()` | ERROR ログ出力 | `$1`：エラーメッセージ | シェル実行ログ・標準エラー出力 |
| `log_cmd()` | コマンドログ出力 | `$1`：実行コマンド文字列 | 詳細ログ |
| `log_rc()` | ReturnCode ログ出力 | `$1`：ReturnCode 値 | 詳細ログ |

---

## 8. ログファイルの権限・保管

| 項目 | 内容 |
|------|------|
| ログファイル権限 | `644`（オーナー：読み書き、グループ/その他：読み取りのみ） |
| 保管期間 | 規定なし（手動管理） |
| 削除 | 自動削除なし（手動削除） |

---

## 9. プロジェクト固有設定：CommandA

### 9.1 ログファイル名（CommandA）

| 区分 | ファイル名 | 例 |
|------|-----------|---|
| シェル実行ログ | `CommandA_YYYYMMDDHHMMSS.log` | `CommandA_20260908143052.log` |
| 詳細ログ | `CommandA_detail_YYYYMMDDHHMMSS.log` | `CommandA_detail_20260908143052.log` |

### 9.2 ログ格納先（CommandA）

| 種別 | パス | 備考 |
|------|------|------|
| ログ格納ディレクトリ | `/var/log/release/`（サーバA） | 資材配置フォルダ（`/opt/release/scripts/`）とは分離 |
| ディレクトリ権限 | `755` | |

### 9.3 出力例（CommandA 正常時）

```
[2026-09-08 14:30:52] [INFO]  処理開始: CommandA.sh
[2026-09-08 14:30:52] [CMD]   mkdir /tmp/testdir
[2026-09-08 14:30:52] [RC]    ReturnCode=0
[2026-09-08 14:30:52] [INFO]  ディレクトリ作成完了: /tmp/testdir
```

### 9.4 出力例（CommandA エラー時）

```
[2026-09-08 14:30:55] [CMD]   mkdir /tmp/testdir 2>&1
[2026-09-08 14:30:55] [RC]    ReturnCode=1
[2026-09-08 14:30:55] [ERROR] E101: ディレクトリ作成失敗（既存） - mkdir /tmp/testdir
```
