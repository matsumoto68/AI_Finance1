## 2. ディレクトリ構成

### 2.1 サーバA（Linux環境）

```
/
├── opt/
│   └── release/
│       └── scripts/                  # スクリプト配置ディレクトリ
│           ├── CommandA.sh           # サーバA向けメインシェルスクリプト
│           ├── CommandB.sh           # サーバB向けメインシェル（SCP転送前の資材）
│           ├── release_all.sh        # オーケストレーターシェル
│           └── deploy_multi.sh       # 複数サーバ向け資材配置シェル
├── var/
│   └── log/
│       └── release/                  # ログ出力ディレクトリ（資材配置フォルダとは分離）
│           ├── CommandA_YYYYMMDDHHMMSS.log           # CommandA シェル実行ログ
│           ├── CommandA_detail_YYYYMMDDHHMMSS.log     # CommandA 詳細ログ
│           ├── release_all_YYYYMMDDHHMMSS.log         # オーケストレーター実行ログ
│           └── release_all_detail_YYYYMMDDHHMMSS.log  # オーケストレーター詳細ログ
└── tmp/
    ├── testdir/                      # 作業ディレクトリ（テスト用）
    │   ├── test.txt                  # ファイル作成（touch）対象
    │   ├── data.txt                  # データファイル
    │   ├── data_bk.txt               # データバックアップファイル
    │   └── renamed.txt               # リネーム後ファイル
    ├── testdir_bk/                   # バックアップディレクトリ（コピー先）
    └── testfile.sh                   # 権限変更対象ファイル
```

### 2.2 サーバB（Linux環境）

## 3. ディレクトリ定義

### 3.1 `/opt/release/scripts/`（サーバA・サーバB共通）

| 項目 | 内容 |
|------|------|
| パス | `/opt/release/scripts/` |
| 用途 | シェルスクリプトの配置ディレクトリ |
| 作成タイミング | 資材配置シェル（`deploy_multi.sh`）実行時に存在しない場合自動作成（サーバA）<br>SCP転送前にサーバB上に存在していること（前提条件） |
| 権限 | `755`（オーナー：読み書き実行、グループ/その他：読み取り・実行） |
| 備考 | 本番・試験環境共通パス |

### 3.2 `/var/log/release/`（サーバA・サーバB共通）

| 項目 | 内容 |
|------|------|
| パス | `/var/log/release/` |
| 用途 | シェルスクリプトの実行ログ出力先（資材配置フォルダとは分離） |
| 作成タイミング | 各シェル（`CommandA.sh` / `CommandB.sh` / `release_all.sh`）の初期化処理（init_log）実行時に存在しない場合自動作成 |
| 権限 | `755` |
| 備考 | ログファイルは実行日時（YYYYMMDDHHMMSS）付きで生成。サーバA・サーバBそれぞれのサーバ上に出力される |

### 3.3 `/tmp/testdir/`（サーバA・サーバB共通）

| 項目 | 内容 |
|------|------|
| パス | `/tmp/testdir/` |
| 用途 | ファイル・ディレクトリ操作コマンドの作業ディレクトリ |
| 作成タイミング | `CommandA.sh` / `CommandB.sh` のディレクトリ操作処理（項番1）で作成 |
| 権限 | `755` |
| 備考 | 処理の最後（項番17）で `rm -rf` により削除される |

### 3.4 `/tmp/testdir_bk/`（サーバA・サーバB共通）

| 項目 | 内容 |
|------|------|
| パス | `/tmp/testdir_bk/` |
| 用途 | `testdir` のバックアップ（ディレクトリコピー先） |
| 作成タイミング | `CommandA.sh` / `CommandB.sh` のディレクトリコピー処理（項番11）で作成 |
| 権限 | コピー元と同じ `755` |
| 備考 | ディレクトリ削除処理（項番15）で削除される |

## 5. 命名規則

### 5.1 シェルスクリプト

| 区分 | 規則 | 例 |
|------|------|----|
| メインシェル | `{コマンドID}.sh` | `CommandA.sh`、`CommandB.sh` |
| オーケストレーターシェル | `release_all.sh` | `release_all.sh` |
| 資材配置シェル | `deploy_{対象}.sh` | `deploy_multi.sh` |

### 5.2 ログファイル

| 区分 | 規則 | 例 |
|------|------|----|
| シェル実行ログ | `{シェル名}_YYYYMMDDHHMMSS.log` | `CommandA_20260908143052.log`、`CommandB_20260908143055.log` |
| 詳細ログ | `{シェル名}_detail_YYYYMMDDHHMMSS.log` | `CommandA_detail_20260908143052.log`、`release_all_detail_20260908143050.log` |

- `{シェル名}`：実行シェルのファイル名（拡張子なし）
- `{YYYYMMDDHHMMSS}`：実行開始日時（年月日時分秒）
- 同日複数回実行しても上書きされず、実行ごとに別ファイルとして保存される

### 5.3 作業ディレクトリ・ファイル

| 区分 | 規則 |
|------|------|
| 作業ディレクトリ | `/tmp/` 配下に作成する |
| バックアップ | 元のディレクトリ名に `_bk` を付与 |
| バックアップファイル | 元のファイル名（拡張子なし）に `_bk` を付与 |

## 6. 権限定義

| 対象 | 権限値 | オーナー | グループ | その他 |
|------|--------|---------|---------|--------|
| シェルスクリプト（.sh） | `755` | rwx | r-x | r-x |
| ログディレクトリ | `755` | rwx | r-x | r-x |
| ログファイル（.log） | `644` | rw- | r-- | r-- |
| 作業ディレクトリ | `755` | rwx | r-x | r-x |

## 7. ディレクトリ・ファイル作成・削除タイミング

### 7.1 サーバA

| ディレクトリ/ファイル | 作成タイミング | 削除タイミング |
|---------------------|--------------|--------------|
| `/opt/release/scripts/` | `deploy_multi.sh` 実行時（存在しない場合に自動作成） | 手動削除（自動削除なし） |
| `/var/log/release/` | `CommandA.sh` / `release_all.sh` 起動時 init_log 処理（存在しない場合に自動作成） | 手動削除（自動削除なし） |
| `/tmp/testdir/` | `CommandA.sh` ディレクトリ作成処理（`mkdir /tmp/testdir`） | `CommandA.sh` ディレクトリ強制削除処理（`rm -rf /tmp/testdir`） |
| `/tmp/testdir_bk/` | `CommandA.sh` ディレクトリコピー処理（`cp -r /tmp/testdir /tmp/testdir_bk`） | `CommandA.sh` ディレクトリ削除（空）処理（`rmdir /tmp/testdir_bk`） |
| `/tmp/testdir/test.txt` | `CommandA.sh` ファイル作成処理（`touch /tmp/testdir/test.txt`） | `CommandA.sh` ファイル移動（リネーム）処理（`mv` によりリネーム） |
| `/tmp/testdir/data.txt` | `CommandA.sh` ファイル作成処理（`echo hello > /tmp/testdir/data.txt`） | `CommandA.sh` ディレクトリ強制削除処理（`rm -rf` による間接削除）＋ `proc_file` 末尾の強制削除（`rm -rf /tmp/testdir`） |
| `/tmp/testdir/data_bk.txt` | `CommandA.sh` ファイルコピー処理（`cp /tmp/testdir/data.txt /tmp/testdir/data_bk.txt`） | `CommandA.sh` ファイル削除処理（`rm /tmp/testdir/data_bk.txt`） |
| `/tmp/testdir/renamed.txt` | `CommandA.sh` ファイル移動（リネーム）処理（`mv /tmp/testdir/test.txt /tmp/testdir/renamed.txt`） | `CommandA.sh` ディレクトリ強制削除処理（`rm -rf` による間接削除）＋ `proc_file` 末尾の強制削除（`rm -rf /tmp/testdir`） |

| ディレクトリ/ファイル | 作成タイミング | 削除タイミング |
