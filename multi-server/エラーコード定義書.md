## 2. エラーコード体系

### 2.1 エラーコード形式

```
E{カテゴリ番号}{連番2桁}
```

### 2.2 カテゴリ定義

| カテゴリ番号 | カテゴリ名 | 説明 |
|------------|-----------|------|
| 0 | 共通・事前チェック | 実行環境・権限確認に関するエラー |
| 1 | ディレクトリ操作 | ディレクトリの作成・移動・コピー・削除に関するエラー |
| 2 | ファイル操作 | ファイルの作成・確認・コピー・移動・削除に関するエラー |
| 3 | サービス操作 | サービスの起動・停止・状態確認に関するエラー |
| 4 | 一覧表示・権限変更 | ls・chmod に関するエラー |
| 5 | オーケストレーター | release_all.sh固有のSSH/SCP・サーバ間連携に関するエラー |
| 9 | 資材配置 | 資材配置シェルに関するエラー |

### 2.3 終了コード

| 終了コード | 意味 |
|-----------|------|
| `0` | 正常終了 |
| `1` | 異常終了（エラー発生） |

## 3. エラー発生時の動作フロー

```
コマンド実行
    │
    ├─ RC チェック / 出力文字列チェック
    │
    ├─ 正常 → 次の処理へ
    │
    └─ エラー検出
          │
          ├─ エラーコードを特定
          ├─ [ERROR] ログをシェル実行ログに出力
          ├─ [CMD][RC] ログを詳細ログに出力
          └─ exit 1（処理中断）
```

### 3.1 エラーログ出力フォーマット

> ログ出力の詳細フォーマットは **ログ設計書.md** を参照。

```
[YYYY-MM-DD HH:MM:SS] [ERROR] {エラーコード}: {エラーメッセージ}
[YYYY-MM-DD HH:MM:SS] [CMD]   {実行コマンド}
[YYYY-MM-DD HH:MM:SS] [RC]    ReturnCode=N
```

## 4. エラーコード一覧：CommandA プロジェクト（サーバA）

### 4.1 共通・事前チェック（E0xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | 対処方法 |
|------------|-----------|---------|---------|---------|
| E001 | ログディレクトリ書き込み権限なし | RC チェック | `/var/log/release` に書き込み権限がない | 実行ユーザーの権限を確認し、ディレクトリの権限を修正する |
| E002 | systemctl コマンド不存在 | コマンド存在確認 | `systemctl` が使用できない環境 | systemd がインストールされているか確認する |

### 4.2 ディレクトリ操作（E1xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E101 | ディレクトリ作成失敗（既存） | 出力文字列チェック | 作成対象ディレクトリがすでに存在する | `File exists` | 既存ディレクトリを確認し、不要であれば削除後に再実行する |
| E102 | ディレクトリ作成失敗（権限なし） | 出力文字列チェック | 実行ユーザーに作成先ディレクトリへの書き込み権限がない | `Permission denied` | 実行ユーザーの権限を確認する（例：`/root/` 配下は一般ユーザー不可） |
| E103 | ディレクトリ移動失敗（不存在） | 出力文字列チェック | 移動先ディレクトリが存在しない | `No such file or directory` | 対象ディレクトリのパスを確認する |
| E104 | ディレクトリコピー失敗 | RC チェック | コピー元が存在しない、または権限不足 | - | コピー元パスおよび権限を確認する |
| E105 | ディレクトリ削除失敗（空ではない） | 出力文字列チェック | `rmdir` 対象ディレクトリが空でない | `Directory not empty` | ディレクトリ内のファイルを確認し、不要なファイルを削除後に再実行する |
| E106 | ディレクトリ強制削除失敗 | RC チェック | `rm -rf` 実行時に権限不足等が発生 | - | 実行ユーザーの権限を確認する |

### 4.3 ファイル操作（E2xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E201 | ファイル作成失敗（touch） | RC チェック | 作成先ディレクトリが存在しない、または権限不足 | - | 作成先ディレクトリの存在と権限を確認する |
| E202 | ファイル作成失敗（echo） | RC チェック | リダイレクト先に書き込み権限がない | - | 書き込み先パスと権限を確認する |
| E203 | ファイル内容確認失敗 | 出力文字列チェック | ファイルに期待する文字列（`hello`）が含まれない | - | ファイルの内容を確認する（E202で正しく書き込まれているか確認） |
| E204 | ファイルコピー失敗 | RC チェック | コピー元が存在しない、または権限不足 | - | コピー元パスと権限を確認する |
| E205 | ファイル移動（リネーム）失敗 | RC チェック | 移動元が存在しない、または権限不足 | - | 移動元パスと権限を確認する |
| E206 | ファイル削除失敗（不存在） | 出力文字列チェック | 削除対象ファイルが存在しない | `No such file or directory` | 削除対象ファイルのパスを確認する |

### 4.4 サービス操作（E3xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E301 | サービス起動失敗 | 出力文字列チェック | nginx が起動できない（設定ファイル不備・ポート競合等） | `Failed to start` / `Failed` | `systemctl status nginx` でエラー詳細を確認する |
| E302 | サービス起動確認失敗 | 出力文字列チェック | 起動後のステータスが `active` でない | - | サービスのログを確認する（`journalctl -xe`） |
| E303 | サービス停止失敗 | RC チェック | nginx が停止できない | - | サービスの状態を確認し、強制停止を検討する |
| E304 | サービス停止確認失敗 | 出力文字列チェック | 停止後のステータスが `inactive` でない | - | プロセスが残っていないか確認する |
| E305 | サービス状態確認失敗 | 出力文字列チェック | `systemctl status` の出力に `Active` が含まれない | - | サービスのインストール状態を確認する |

### 4.5 一覧表示・権限変更（E4xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E401 | 一覧表示失敗 | 出力文字列チェック | `ls` の出力に `total` が含まれない | - | 対象ディレクトリのパスと権限を確認する |
| E402 | ファイル権限変更失敗 | RC チェック | `chmod` 対象ファイルが存在しない、または権限不足 | - | 対象ファイルのパスと実行ユーザーの権限を確認する |

## 5. エラーコード一覧：CommandB プロジェクト（サーバB）

CommandB.shのエラーコードはCommandA.shと同一体系（E0xx〜E4xx）を使用する。各エラーコードの定義・検出方式・発生条件・対処方法はセクション4と同一。

> ※ サーバB環境固有のパス・サービス名が異なる場合でも、エラーコード体系は共通とする。

## 6. エラーコード一覧：release_all.sh オーケストレーター（サーバA上で実行）

### 6.1 オーケストレーター固有（E5xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E500 | SSH接続確認失敗 | 出力文字列チェック | サーバBへのSSH接続確認で `ok` が返らない | - | サーバBのSSH設定・ネットワーク接続・秘密鍵パスを確認する |
| E501 | SCP転送失敗 | RC チェック | CommandB.shのサーバBへのSCP転送に失敗 | - | サーバBの接続情報・配置先ディレクトリの権限を確認する |
| E502 | サーバA処理失敗（CommandA.sh） | RC チェック | CommandA.shの実行がエラー終了した | - | CommandA.shのログを確認し、エラー原因を特定する |
| E503 | サーバBリモート実行失敗（CommandB.sh） | RC チェック | SSH経由のCommandB.shリモート実行がエラー終了した | - | サーバB上のCommandB.shログを確認し、エラー原因を特定する |
| E504 | 接続情報読み込み失敗 | 値チェック | ホスト名・ユーザー名・秘密鍵パスのいずれかが空 | - | 設定ファイルまたは実行時パラメータの値を確認する |
| E505 | 秘密鍵ファイル不存在 | ファイル存在確認 | 指定された秘密鍵ファイルが存在しない | - | 秘密鍵ファイルのパスを確認する |
| E506 | CommandA.sh 不存在 | ファイル存在確認 | `/opt/release/scripts/CommandA.sh` が存在しない | - | deploy_multi.shによる資材配置が完了しているか確認する |
| E507 | CommandB.sh 不存在 | ファイル存在確認 | `/opt/release/scripts/CommandB.sh` が存在しない | - | deploy_multi.shによる資材配置が完了しているか確認する |

### 6.2 エラー発生時の動作（release_all.sh固有）

| エラーコード | 発生時の動作 |
|------------|------------|
| E500 | エラーログ出力 → 以降の全処理を中断して `exit 1` |
| E501 | エラーログ出力 → SSHリモート実行をスキップして `exit 1` |
| E502 | エラーログ出力 → サーバB処理（SCP転送・リモート実行）を一切実行せずに `exit 1` |
| E503 | サーバBのエラー内容をサーバAのオーケストレーターログに記録 → `exit 1` |
| E504 | エラーログ出力 → 以降の全処理を中断して `exit 1` |
| E505 | エラーログ出力 → 以降の全処理を中断して `exit 1` |
| E506 | エラーログ出力 → 以降の全処理を中断して `exit 1` |
| E507 | エラーログ出力 → 以降の全処理を中断して `exit 1` |

## 7. エラーコード一覧：deploy_multi.sh 資材配置シェル（サーバA上で実行）

### 7.1 資材配置（E9xx）

| エラーコード | エラー内容 | 検出方式 | 発生条件 | エラーメッセージ（Linux出力） | 対処方法 |
|------------|-----------|---------|---------|--------------------------|---------|
| E901 | 配置元ファイル不存在（CommandA.sh） | ファイル存在確認 | `CommandA.sh` がカレントディレクトリに存在しない | - | `CommandA.sh` の配置を確認する |
| E902 | 配置先ディレクトリ作成失敗 | RC チェック | `/opt/release/scripts/` の作成に失敗 | - | 実行ユーザーの `/opt/` 配下への書き込み権限を確認する |
| E903 | ファイルコピー失敗 | RC チェック | 配置先へのコピーに失敗（権限不足等） | - | 配置先ディレクトリの権限を確認する |
| E904 | 実行権限付与失敗 | RC チェック | `chmod 755` の実行に失敗 | - | 実行ユーザーのファイル所有権を確認する |
| E905 | 配置元ファイル不存在（CommandB.sh） | ファイル存在確認 | `CommandB.sh` がカレントディレクトリに存在しない | - | `CommandB.sh` の配置を確認する |
| E906 | 配置元ファイル不存在（release_all.sh） | ファイル存在確認 | `release_all.sh` がカレントディレクトリに存在しない | - | `release_all.sh` の配置を確認する |
