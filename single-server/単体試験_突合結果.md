## 4. 問題点・要対応事項

### ❌ D-03：ディレクトリ作成（権限なし）RC 不一致

| 項目 | 内容 |
|------|------|
| 試験No | D-03 |
| 試験項目 | ディレクトリ作成（権限なし・エラー確認） `mkdir /root/noperm` |
| 期待RC | 1（Permission denied） |
| 実際RC | **0** |
| 推定原因 | 試験実行環境がroot権限で動作していた可能性。Docker/コンテナ環境などでrootユーザー相当の環境だった場合、`/root/noperm` への mkdir が成功してしまう |
| 対応方針 | 試験環境を確認し、**一般ユーザー（`$` プロンプト）** で CommandA.sh を再実施する |

---

### ⚠️ E-01（UT異常系）：ログディレクトリ書き込み権限エラー

| 項目 | 内容 |
|------|------|
| 試験No | E-01（UT異常系） |
| 内容 | UT異常系の `CommandA_A01_stderr.log` に `[ERROR] E001: ログディレクトリ書き込み権限なし: /var/log/release` が出力されている |
| 判断 | これは UT異常系試験の前提条件（ログディレクトリに書き込み権限がない状態）として**意図的に発生させた**エラーと考えられるため、異常系試験としては正常な結果 |
| 正常系への影響 | UT正常系では正常にログ生成されており問題なし |
